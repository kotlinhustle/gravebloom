# Gravebloom

2D arena-battler prototype for Godot 4.

## How to run

1. Open Godot 4.
2. Import this folder as a project.
3. Make sure the renderer is set to Compatibility.
4. Run the main scene: `res://scenes/main.tscn`.

## Controls

- `WASD` - move.
- Touch or left mouse drag - mobile-style movement.

## Current prototype

- The Masked Wanderer moves around a dark ruined arena.
- Enemies spawn around the player and chase them.
- The living blade automatically attacks the nearest enemy.
- Enemies drop XP shards.
- Level-ups pause the game and offer relic upgrades.
